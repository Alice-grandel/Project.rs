 # 🧠 Exercícios de Lógica de Programação em java
 

Este repositório contém exercícios de lógica de programação que estou resolvendo para treinar minha base em desenvolvimento e fortalecer meu raciocínio lógico, usando a linguagem **JAVA**.

---

✍️ Objetivo

Praticar a lógica de programação de forma consistente, reforçando conceitos fundamentais como:

    Declaração de variáveis

    Tipos de dados

    Estruturas de decisão (if, else if, else)

    Laços de repetição (for, while, loop, do while)

    Funções

    Vetores (Vec<T>, arrays)

    Manipulação de entrada e saída

    Pequenos projetos com foco em lógica
